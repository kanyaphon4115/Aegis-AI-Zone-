# ทดสอบระบบก่อนขึ้นจริง

รันคำสั่งเดียวจากโฟลเดอร์หลักของโปรเจกต์:

```bash
npm run test
```

จะจำลองฐานข้อมูลในหน่วยความจำแล้วเดินระบบจริงทั้งเส้นทาง 35 ข้อ:
สมัคร → เข้าสู่ระบบ → สแกนจนโควตาหมด → สิทธิ์ Pro ถูกกั้น → ส่งสลิป →
เข้าหลังบ้าน → ดูข้อมูลลูกค้า → ยืนยันสลิป → แพ็กเกจเปิดทันที → ปฏิเสธสลิป → เปิดแพ็กเกจด้วยมือ

ไม่แตะฐานข้อมูลจริงและไม่เรียก AI จริง จึงรันซ้ำได้ฟรีตลอด
